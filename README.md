Project Title:
Nike Landing Page – ReactJS Figma Clone
Description:
A modern, responsive Nike-themed landing page built with ReactJS and CSS, inspired by a Figma design.
This project demonstrates my ability to convert UI/UX mockups into functional, pixel-perfect web pages using clean React components and reusable styling.
Key Features:
Responsive Hero Section with headline, description & call-to-action buttons .Interactive Navigation Bar with dynamic layout. Realistic Product Image Display and brand logos. Organized Component-Based Architecture (Hero Section, Navbar). Developed using Vite + React for fast build and development.
Tech Stack:
ReactJS
Vite
HTML5
CSS3
Purpose:
This project was created to strengthen my front-end development skills, particularly in ReactJS UI building, and to demonstrate design-to-code conversion capabilities.
